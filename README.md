# GH 학교 설문 — 설정 가이드 (구글 로그인 버전)

## 파일 구성
| 파일 | 역할 |
|---|---|
| index.html | 앱 전체 (구글 로그인, 내 정보, 설문 목록·만들기·참여·결과) |
| manifest.json, service-worker.js, icon-*.png | 폰에 앱처럼 설치되게 해주는 파일 |
| firestore.rules | 데이터 보안 규칙 (파이어베이스 콘솔에 붙여넣기) |

## 중복 참여를 막는 방법
1. 구글 계정 1개 = 계정 1개
2. 학년·반·번호 1자리 = 계정 1개 (먼저 등록한 사람이 주인)
3. 설문 1개당 계정 1개 = 응답 1번 (수정·재제출 불가)
세 가지 모두 파이어베이스 서버의 보안 규칙이 막기 때문에, 앱을 지우거나 기기를 바꿔도 다시 참여할 수 없어요.

## 1. 체험 모드
설정 없이 올리면 체험 모드예요. 로그인 버튼을 누르면 아무 이메일로 들어갈 수 있고, 데이터는 그 기기에만 저장돼요.

## 2. 파이어베이스 프로젝트 만들기 (무료, 카드 필요 없음)
1. https://console.firebase.google.com → 프로젝트 만들기 (애널리틱스는 꺼도 됨)
2. 프로젝트 홈에서 웹 아이콘 `</>` → 앱 이름 입력 → 앱 등록

## 3. 설정값 붙여넣기
나오는 `firebaseConfig = { ... }` 값을 index.html 아래쪽 `const firebaseConfig = { ... }` 부분에 붙여넣기

## 4. 구글 로그인 켜기
1. Authentication → 시작하기 → 로그인 방법 → **Google** → 사용 설정 → 지원 이메일 선택 → 저장
2. Authentication → 설정 → 승인된 도메인 → 도메인 추가 → `rnsdnlrh1022.github.io`

## 5. 데이터베이스 만들기
1. Firestore Database → 데이터베이스 만들기 → 위치 `asia-northeast3 (Seoul)` → 프로덕션 모드
2. 규칙 탭에 `firestore.rules` 내용을 전부 붙여넣고 게시

## 누가 내 번호를 먼저 등록했을 때
Firestore Database → 데이터 → `seats` → 해당 번호 문서(예: `2-3-15`)를 삭제하면
진짜 주인이 다시 등록할 수 있어요.
