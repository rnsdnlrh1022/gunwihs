# GH 학교 설문 — 설정 가이드

## 로그인 종류
| 구분 | 로그인 방법 | 할 수 있는 것 |
|---|---|---|
| 학생 | 구글 계정 → 학년·반·번호·성별 | 설문 참여, 설문 만들기, 내 설문 결과 보기 |
| 선생님 | 구글 계정 → 이름 + 선생님 비밀번호 | 설문 만들기, **모든 설문 결과 보기** |
| master(마스터) | 구글 계정 → master 비밀번호 → 학년·반·번호 | 모든 설문 결과·삭제, 학생 목록·접속 기록, 학생 초기화, 선생님 권한 해제, 비밀번호 변경 |

비밀번호는 사이트 코드에 없고 **Firebase의 `config/secrets` 문서에만** 저장돼요. 이 문서는 아무도 읽을 수 없고, 보안 규칙만 몰래 비교해요.

## 처음 한 번만 하는 설정 (Firebase 콘솔)
1. (익명 로그인은 필요 없어요. 모두 구글 로그인만 써요.)
2. **보안 규칙 바꾸기**: Firestore Database → 규칙 → `firestore.rules` 내용으로 전부 바꾸고 게시
3. **비밀번호 저장하기**: Firestore Database → 데이터 → 컬렉션 시작
   - 컬렉션 ID: `config`
   - 문서 ID: `secrets` (자동 ID 쓰지 말고 직접 입력)
   - 필드 `teacherPin` / 유형 **string** / 값 선생님 비밀번호
   - 필드 `masterPin` / 유형 **string** / 값 master 비밀번호
   - 유형을 number로 하면 앞의 0이 사라져서 로그인이 안 돼요. 꼭 **string**!
4. 그 뒤로는 master 화면의 **비밀번호** 탭에서 바꿀 수 있어요.

## 중복 참여를 막는 방법
1. 구글 계정 1개 = 학생 1명
2. 학년·반·번호 1자리 = 계정 1개 (먼저 등록한 사람이 주인)
3. 설문 1개당 학생 1명 = 응답 1번
4. 선생님도 설문에 응답할 수 있어요. 대상을 "선생님 전용"으로 하면 선생님만 보고 응답해요
5. 한 번 선생님으로 확인한 구글 계정은 다음부터 비밀번호 없이 선생님으로 들어가요

## 선생님 전용 설문
- 설문 만들 때 대상에서 **선생님 전용**을 고르면 선생님만 응답할 수 있어요.
- 학생에게는 서버가 아예 보내지 않아서 제목도, 올라왔는지도 알 수 없어요. (링크로 들어와도 "없는 설문"으로 보임)
- master는 볼 수 있고 결과도 확인할 수 있어요.
- 선생님은 전체 대상 설문과 선생님 전용 설문에 응답할 수 있어요.

## master 기능
- **학생**: 등록한 학생 목록, 가입일, 마지막 접속 시간, 올린 설문. 번호순/최근 접속순 정렬
- **초기화**: 학생 한 명 또는 전체의 등록(학년·반·번호)을 지움 → 다음 로그인 때 다시 입력
  (이미 참여한 설문은 초기화해도 다시 참여할 수 없어요)
- **설문**: 모든 설문의 작성자, 응답 수, 결과 보기, 삭제
- **선생님**: 선생님으로 로그인한 기록, 권한 해제
